# 📚 Booksky

Booksky is a simple and user-friendly web application for managing personal book notes. It allows users to add, view, and delete book entries with an attractive and responsive interface.

## 🚀 Features

* 📖 Add new books
* 📝 Store book title, author, and description
* ❌ Delete books easily
* 💻 Responsive and clean user interface
* ⚡ Fast and lightweight

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```
Booksky/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Keerthi-Jeslin-06/Booksky.git
```

2. Open the project folder.

3. Double-click `index.html` or open it with **Live Server** in Visual Studio Code.
